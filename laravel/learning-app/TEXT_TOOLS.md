# テキスト便利ツール集の詳細

[導入・起動方法はREADME](README.md)を参照してください。`/text-tools`で利用できます。

## 画面と操作

`/text-tools`は「テキスト整形」「置換・文字変換」「行の整理」「正規表現」の4用途を切り替える画面です。選択した設定だけ詳細を表示し、用途ごとの入力・設定・結果を画面内で保持します。正規表現は候補作成・期待例の検証・一致確認と強調/グループ表示・サンプル生成を備えます。入力例挿入・結果引継ぎ・用途をまたぐ一括処理は設けず、結果のコピーと手動貼り付けで続けて使います。貼り付けボタンが使えない場合は右クリック/長押しメニューを案内します。クリアは現在の入力と結果を消し、選択設定を保持します。

## 文字数・サイズと上限

文字数は改行を含むコードポイント数、入力は10万文字、検索語・置換語・正規表現と候補作成の入力/検証例は各1,000文字、結果は100万文字までです。上限超過は切り捨てず中止し、入力を保持します。10万文字を超える結果をほかの用途へ貼り付ける場合は入力上限にかかります。表示するUTF-8バイト数はBOMなし・改行LFでのサイズです。

## ファイル保存と入力の扱い

「テキストファイルを保存」はブラウザーでUTF-8 Blobを生成し、`text-result.txt`として端末へ保存します。サーバーに生成・保管せず、保存用の共有URLも作りません。一時Blob URLは60秒後またはページ離脱時に解放します。保存ファイルの削除は端末側で行います。空の正常結果も保存可能です。JavaScriptでブラウザー内処理し、アプリは入力や結果をAPI・DB・Web Storage・URLへ保存/送信しません。ページには広告・解析を導入できるため、通信なしや機密入力の安全性は保証しません。

## 正規表現の制限

正規表現はWorker内で実行し1秒で中止。編集・候補作成はu固定、一致確認はJavaScript構文とi/m/s/u、生成は限定ASCII構文とuのみです。生成後は同じ式で文字列全体への一致を検証します。後方参照・先読み/後読み・否定クラス・ドット・Unicodeプロパティなどの生成は未対応で、要求数に達しない場合があります。入力10万・パターン/置換語1,000・結果100万コードポイント、一致表示1,000件、生成1〜10件/1件256文字の上限があります。

## テストと広告・解析設定

`npm run test:js`と`php artisan test --compact --filter=TextTools`、起動後に`npm run test:browser:text-tools`で確認できます。広告は既存設定を再利用し、解析は本番の`ANALYTICS_ENABLED=true`と`ANALYTICS_MEASUREMENT_ID`で有効化。解析イベントは固定ツール名・成功/失敗分類のみで入力内容を含めません。公開サンプルに実IDは含めません。
