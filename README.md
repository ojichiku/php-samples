# PHP Samples

PHPの学習・動作確認に使うサンプルコード集です。
フレームワークやテーマごとにフォルダーを分け、サンプルごとのREADMEに導入・起動・確認方法をまとめています。

## サンプル一覧

| 分類 | サンプル | 内容 |
| --- | --- | --- |
| Laravel | [learning-app](laravel/learning-app/README.md) | 共通メニュー、サーバー/ブラウザー別のパスワード生成、年間カレンダー、Hello World、入力フォーム |

## フォルダー構成

```text
php-samples/
├── README.md
├── LICENSE
└── laravel/
    └── learning-app/
        └── README.md
```

Laravel以外のサンプルを追加する場合は、内容に合う分類フォルダーを作り、その配下にサンプルを配置します。
各サンプルは自分のフォルダー内で依存導入・起動・テストを実行します。

## 利用方法

GitHubから取得した後、使いたいサンプルのREADMEを開いてください。
必要なPHPのバージョンや追加ツールはサンプルごとに異なります。

環境設定ファイルは`.env.example`を元に各自で作成します。
実際の`.env`、認証情報、データベース、ログ、依存ライブラリの実体はリポジトリへ追加しないでください。
